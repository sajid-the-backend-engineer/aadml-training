# Security

Please report a security problem privately, never in a public issue: use GitHub's **Report a vulnerability** on this
repository's Security tab. Say what you found, how to reproduce it, and which version you used. We answer as soon as we
can and tell you when it is fixed.

Never include a real API key in a report, an issue or an example. If you published one by mistake, revoke it on your
project's Deploy page and make a new one.
